
# Sistema Inteligente de Clasificación y Análisis de Palabras mediante Inteligencia Artificial



## Tech Stack

**Server:** python 3.13.3



## instalacion
Clonar el proyecto

```bash
git clone https://github.com/GalvanNelson/Palabras_palindormas_con_IA.git
```

### Instalacion backend

```bash
  cd backend
```

Instalacion de las dependencias

```bash
py -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```

Iniciar el servicio

```bash
uvicorn main:app --reload
```
